# Слой

Учебный интернет-магазин стройматериалов. Покупатель выбирает фанеру, плитку или клей, рассчитывает количество упаковок плитки и оформляет заказ на самовывоз. Администратор управляет ассортиментом, остатками и заказами.

## Первый запуск в Open Server Panel 5

1. Поместите папку **sloy** в **C:\OSPanel\domains\localhost**. Файл index.php должен оказаться непосредственно в папке sloy.
2. В меню Open Server выберите Apache с PHP 8.1 и MySQL 8.0. Нажмите «Запустить». Для работы нужны расширения PHP pdo_mysql и mbstring.
3. Откройте phpMyAdmin через меню панели. Создайте пустую базу **sloy_db** с кодировкой utf8mb4. Выберите эту базу, откройте вкладку «Импорт» и укажите **database/sloy.sql**. В файле есть таблицы, ассортимент и учебная учётная запись.
4. По умолчанию магазин подключается к MySQL на 127.0.0.1, порт 3306, пользователь root, пароль пустой. Если ваши параметры отличаются, скопируйте config.example.php в config.local.php и укажите их в копии.
5. Откройте [магазин](http://localhost/sloy/). При следующем запуске достаточно включить Open Server и открыть этот адрес.

Для доступа к управлению магазином после импорта войдите с почтой **admin@sloy.local** и паролем **SloyDemo2026!**. [Вход в магазин](http://localhost/sloy/login/)

## Файлы проекта

| Путь | Назначение |
| --- | --- |
| index.php | Точка входа сайта |
| api.php | Обработка форм корзины, заказа, входа и администрирования |
| app/ | Подключение к MySQL, запросы, выбор страниц и вывод карточек |
| views/ | Шаблоны витрины, каталога, товара, корзины, кабинета и администрирования |
| assets/ | Стили, JavaScript, значок сайта и фотографии материалов |
| database/ | Схема таблиц и готовая база для импорта |
| data/ | Файлы сеансов покупателей |
| docs/ | Технические задания на разработку и SEO |
| tests/ | Проверка страниц работающего магазина |
| bin/ | Установка в пустую базу для разработки |
| robots.php, sitemap.php | Правила для поисковиков и карта страниц |

Apache использует правила адресации из .htaccess. При публикации укажите полный адрес магазина в параметре public_url. Адреса товаров, канонические ссылки и карта сайта учитывают папку установки.
